# ARC Electrical & Gas — Website

Professional website for ARC Electrical & Gas (Leeds) Ltd. Built with Next.js 14, TypeScript and Tailwind CSS.

## Tech Stack

- **Framework**: Next.js 14 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Deployment**: Vercel

## Getting Started

```bash
npm install
npm run dev
```
